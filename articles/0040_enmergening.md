# New major features on Nightly! Or: The Enmergening...

The Nightly versions of YARG have a lot of new major features on them that we want you all to check out and beta test before the next Stable update!

## Carrer Mode

Career Mode is finally in YARG! Included with the game are two careers using the YARG Official Setlist, one focused on Rock/Metal music and one focused on Pop music, but as promised, customs are supported! You can make custom careers inside of the Presets editor in Settings.

## UI Reorganizations

Two pretty major UI reorganizations, firstly: The settings menu has been fully re-done! The new UI is still a work in progress, especially visually, but the new layout is something we quite like, with the old headers now in tabs on the left.

Secondly, we're starting to rearrange the main menu and playing around with what game modes should be featured or hidden. With this, the Practice mode button has been moved inside of Game Modes, alongside the new experimental Career Mode.

## 6-Fret Guitar Support

If you somehow missed it, 6F guitar support is now also here! Like all Nightly features, especially major gameplay ones, expect bugs and issues, and the visuals are something we plan to tweak over time. If you have an old GHL guitar laying around, it may be time to pull it out! (assuming the strum bar isn't too sticky)

## Other Things

As well, some newly added features include:

- ASIO/WASAPI exclusive support for lower latency audio (especially nice on Vocals)
- Custom profile avatars (.png only for now)

In the near future, we plan on releasing the long awaited Profiles Rework, which separates out Players from Controllers from Bindings, making setup in a multiplayer setting much smoother. With this will eventually come an overshell UI for in-game profile editing!

As well, online multiplayer is something we want to merge in very soon, but it is third in the prority list of Career Mode improvements and Profiles Rework, but stay tuned, as with the power of Open Source™ anything can happen at light speed.

We hope you all enjoy the new features, and we can't wait to bring more to YARG!
