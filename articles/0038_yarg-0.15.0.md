# Major Update (v0.15)

We're proud to present one of YARG's biggest updates yet, adding in new gameplay features, polish, and UI. Without further ado, **YARG v0.15**!

v0.15 adds in many highly-requested (and necessary) features to YARG's 
gameplay, making the game feel more complete and able to play a larger set of charts. As well, visual upgrades to the user interface polish the YARG experience outside of direct gameplay!

## Note for Windows users

Due to using Unity 6.3, YARG on Windows has new minimum Windows version requirements: **Windows 10 21H1** or newer or **Windows 11 21H2** or newer. If you are experiencing a crash on launch, please upgrade Windows.

## Basic Changelog

- **Roll/Trill Lanes and Big "YARG" Endings**
  - Lanes work on all instruments (minus vocals), and are customizable via Engine Presets
  - BRE's also support being placed mid-chart using the `midcoda_start` and `midcoda_end` event in charts.
- **New Song Select/Score Screen UI**
  - Fun fact: the old UI was added in v0.12, making this update over 2 and a half years in the making!
- **Custom Vocalist Characters**
  - You can now set a custom VRM based model as the vocalist character in venues!
  - See pins in #venue-artist (venue-artist) for a video tutorial on how to get models to load properly.
  - This feature is still experimental! Expect animations to not look perfect and for some model-related bugs to occur.
- **Beginner Difficulty**
  - If a chart has an Easy difficulty, an automatically-generated Beginner difficulty is created replacing all notes with "wildcard" notes (no specific fret).
- **Drums Lane Customization**
  - Give kick its own specific lane, split toms into individual tom and cymbal lanes, and reorder lanes in any order!
- **Genrelizer**
  - There is now custom sorting for chart genres, splitting songs into a "main genre" and "subgenre".
  - Available setting to further sort songs into 12 more basic genres (Overgenrelizer).
- **Song Select Filters**
  - Song Select now has a filters menu where you can slice and dice your 
    library, making large music libraries much easier to handle.
- **In-Game Calibration**
  - When playing a song, you can now select auto-calibration for video or 
    audio to help you get your calibration dialed in. Just play 
    the song and your timing offset will be used to set the video or audio 
    calibration values.
- **Highway Customization**
  - Add custom highway backgrounds to your highway preset.
  - Make your highway partially (or fully!) transparent.
- And much more...
